# sf1tzp/homebrew-tap

Homebrew casks for [sf1tzp](https://github.com/sf1tzp) projects.

```sh
brew install --cask sf1tzp/tap/primetime
```

| Cask | Description |
| --- | --- |
| [`primetime`](Casks/primetime.rb) | [PrimeTime](https://primetime.tools) — menu-bar time tracker that turns your day into queryable `key: value` data |

Cask versions are bumped automatically by each project's release pipeline.
